# 🧠 Project 2 – Logic Box

Logic Box is a beginner-friendly Python console application that combines **pattern generation** and **number analysis** in one menu-driven program.

## 📌 Features

### 1. Generate a Pattern
- Right-angle star pattern
- Left-angle star pattern
- User can choose the number of rows

### 2. Analyze a Range of Numbers
- Checks whether numbers are **Even or Odd**
- Calculates the **sum** of numbers in the given range
- Validates the starting and ending numbers
- Displays error messages for invalid input

### 3. Exit
- Allows the user to safely exit the program

- Type Casting
- `if-elif-else`
- `match-case`

- `while` loop
